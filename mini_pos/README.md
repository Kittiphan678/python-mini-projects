# 🛒 Mini POS System (CLI)

![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python&logoColor=white)
![Status](https://img.shields.io/badge/Status-Completed-success)

ระบบคิดเงินหน้าร้านขนาดเล็ก (Point of Sale) แบบทำงานผ่าน Command Line Interface (CLI) พัฒนาด้วยภาษา Python เพื่อจำลองระบบการทำงานพื้นฐานของแคชเชียร์ ตั้งแต่การยืนยันตัวตน การคำนวณราคาสินค้า ส่วนลดสมาชิก ไปจนถึงการสรุปยอดขายประจำวัน

---

## ✨ ฟีเจอร์หลัก (Features)

* **🔐 ระบบล็อกอินแคชเชียร์ (Cashier Authentication):** ตรวจสอบชื่อผู้ใช้และรหัสผ่าน พร้อมระบบล็อกบัญชีอัตโนมัติหากกรอกผิดเกิน 3 ครั้ง
* **🧾 ระบบคิดเงินและคำนวณส่วนลดอัตโนมัติ (Billing & Discount Calculation):**
  * รองรับการเพิ่มรายการสินค้าหลายรายการในหนึ่งบิล
  * คำนวณส่วนลดสำหรับสมาชิกอัตโนมัติ (`5%` เมื่อยอดซื้อต่ำกว่า 500 บาท และ `10%` เมื่อยอดซื้อตั้งแต่ 500 บาทขึ้นไป)
* **📊 สรุปยอดขายรายวัน (Daily Sales Summary):** แสดงจำนวนบิลทั้งหมดที่ขายได้และยอดขายสุทธิสะสมของวัน

## 🛠️ การติดตั้งและใช้งาน (Getting Started)

### สิ่งที่ต้องมี (Prerequisites)
* **Python 3.10 ขึ้นไป** (เนื่องจากมีการใช้งานโครงสร้าง `match-case`)
### วิธีรันโปรแกรม
1. ดาวน์โหลดหรือ Clone ไฟล์ไปยังเครื่องของคุณ
2. เปิด Terminal / Command Prompt ในโฟลเดอร์ที่เก็บไฟล์ไว้
3. รันคำสั่ง:
   ```bash
   python mini_pos.py
